# 1000.1.10

Thorough testing found that ambiguous marching-squares cells connected the wrong contour edges. In diagonal saddle cells this could create incorrectly joined or separated snowline contours. The contour generator now uses the bilinear asymptotic determinant with a deterministic exact-saddle tie rule. Both live-map and MP4 contours use this corrected generator.

Three regression tests cover both diagonal sign patterns, an asymmetric cell where a corner average gives the wrong topology, and sign-invariant exact ties. The original implementation fails two of these tests; the corrected implementation passes all three.

Validation: 122 unit tests, production build, live Windy desktop/mobile controls, full-opacity shading/relief checks, full MP4 download and independent H.264 decoding, plus Norway/date-line contour rendering. Expanded published-1000.1.9 testing also checked narrow/landscape controls, rapid timeline and zoom changes, cancellation, identical repeat downloads, Jordan/Norway/date-line coverage, failed-request recovery and cleanup. See [QA report](QA_1000_1_10.md) for exact scope and limitations.
