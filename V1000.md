# Wintry Forecast v1000.0.2

Built from the original standalone v301.0.2 release.

## Easier everyday use

- Wider, more legible panel with larger location and saved-place controls.
- Selected location stays accessible in the panel, with direct Forecast and Sounding buttons.
- Forecast time slider uses available model timestamps, with previous/next controls, Now, and local-calendar day shortcuts.
- Time controls appear in both the main panel and the forecast/sounding window, synchronized through Windy's timeline.
- Larger chart tabs, values, tooltips, and information text; visible keyboard focus indicators.
- Existing ECMWF diagnostics, terrain treatment, snow estimates, saved locations, and units are preserved.
