# 1000.0.13 — development candidate, not published

- Shared exact interval support for liquid totals, gross snowfall and event totals.
  Partial source intervals no longer extend beyond their real end.
- Separate cumulative snowfall from an experimental remaining new-snow layer.
  Water-equivalent snow mass survives compaction; warm dry intervals can melt it.
- Missing precipitation, wet profiles or time coverage never become zero snowfall.
  Missing dry thermal data invalidates remaining snow when a layer is present.
- Positive precipitation traces have the same wet meaning in maps, cards,
  soundings and events. Invalid negative values remain unavailable.
- Mask pressure levels below source-model terrain when its metadata is known.
- Point-only experimental upslope/down-slope diagnostic from above-terrain winds
  and a fixed 4 km DEM span. No extra weather requests, no per-pixel uplift work,
  no uncalibrated rainfall multiplier. Source QPF remains unchanged.
- Cached derived snowfall profiles keep slider changes from rebuilding all profiles.
- Colours, independent map controls, search, saved locations, sounding, exports,
  forecast preparation and existing rendering caches are retained.

See [METHODS.md](METHODS.md) for units, assumptions, sources and scientific limits.
